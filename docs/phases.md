# Implementation phase record

The initial repository contained only `.git`. There was no existing application or code to preserve. The implementation was delivered as a single end-to-end local application, with the following milestones. Early milestones were code-complete before integrated execution; they were not independently tested or deployed as separate releases.

| Phase | Files introduced / subsequently modified | Implemented | Verification / limits | Next |
| --- | --- | --- | --- | --- |
| 1 Foundation | `backend/app/{core,models,auth,main}.py`; `frontend/{package.json,vite.config.ts,tsconfig.json,src/main.tsx,src/App.tsx,src/styles.css}` | Persistent SQLite/PostgreSQL models, registration/login/JWT, owner checks, dashboard shell | Authentication and owner isolation verified in integrated backend tests; no historical phase-specific run claimed | Documents |
| 2 Documents | `backend/app/ingestion.py`, document routes, sample corpus, upload/detail/repository views | Seven file formats, metadata, page/section chunks, statuses, jobs, duplicates, reprocess/delete/export | Real PDF/DOCX and other-format integration tests; scanned/encrypted PDFs fail explicitly | NLP |
| 3 NLP | `backend/app/nlp.py`, entity models/routes/inspector | Text-bound entities, aliases, typed annotations, normalization, audited corrections, explicit relations/negation | Entity/provenance tests pass; dictionary baseline, no claim of comprehensive biomedical NER | Graph |
| 4 Graph | `backend/app/graph.py`, `graph/cypher/schema.cypher`, graph view | NetworkX graph, optional fixed-query Neo4j mirror, evidence, expansion, paths, filters | Graph/path/negation tests pass; Neo4j server unavailable and not exercised | Vectors |
| 5 Retrieval | `backend/app/vectors.py`, `backend/app/vector_store.py`, `backend/app/retrieval.py`, search view | Persisted SQL vectors, optional durable FAISS index, BM25, actual similarity scores, filters, configurable ranking | All four retrieval modes and actual FAISS persistence/cache tested; default vectors are lexical hashing; SentenceTransformer option requires model setup | RAG |

| 10 Reliability/deployment | Dependency locks, Alembic files, Docker/Compose/Render/Vercel configs, scripts, README/docs | Reproducible local setup, non-root backend image, persistent storage config, dependency audit fixes, CLI/migration commands | Exact results in `verification.md`; Docker, PostgreSQL, Neo4j and hosted deployment not verified | External-service and biomedical evaluation |

Run the application and tests using README commands. `scripts/start-local.ps1 -BackendPort 8007 -FrontendPort 5177` supports alternate ports when the defaults are occupied. Use `python scripts/manage.py --help` for administrative command syntax. No unverified hosted deployment or biomedical accuracy result is claimed.
