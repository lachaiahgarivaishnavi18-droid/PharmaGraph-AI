## 3. Free-only persistence and costs

The root `render.yaml` requests exactly:

- `pharmagraph-api`: Docker web service, **free**, Singapore.
- `pharmagraph-demo-db`: PostgreSQL, **free**, Singapore.
- No paid disk or paid service plan.

Render's free web filesystem is ephemeral. This app therefore uses PostgreSQL for users, sessions, documents, passages, vectors and graph evidence. `DOCUMENT_STORAGE=database` stores original upload bytes in the `document_files` table, allowing reprocessing after web restarts. No scientific content relies on `/app/runtime` surviving a restart. `DEPLOYMENT_TARGET=render-free` rejects startup with local SQLite or filesystem upload storage.

**Important:** Render Free PostgreSQL expires **30 days after creation**, has 1 GB of capacity and no managed backups. The free API sleeps when idle and can take time to wake. This is a temporary demo, not permanent production hosting. Export needed data before expiry. Use a separately provided durable PostgreSQL service for longer retention, or request approval before any paid upgrade. Do not create the database long before the source can deploy, because its expiry clock starts at creation.

Review free-tier bandwidth/build limits and the workspace's spend controls before deployment. Do not upgrade plans, add paid disks, add payment methods or enable billable overages without explicit user approval.

Current authoritative constraints: https://render.com/docs/free

## 6. Connect the existing Vercel frontend

After the backend is healthy, update the **existing** Vercel project `pharmagraph-ai`, Production environment:

```text
VITE_API_BASE_URL=https://ACTUAL_BACKEND_HOST/api/v1
VITE_BACKEND_PENDING=false
```

`VITE_API_URL` remains supported as a backwards-compatible alias; `VITE_API_BASE_URL` takes precedence. The URL is public configuration, not a secret. Never put backend credentials into a `VITE_` variable.

**A Vercel redeployment is required:** Vite embeds these variables during its build. Changing a Vercel variable does not modify an already-built JavaScript bundle. Redeploy the linked existing project, preserving `https://pharmagraph-ai-nine.vercel.app`. Do not create another Vercel project and do not turn off the pending notice before the backend is verified.
